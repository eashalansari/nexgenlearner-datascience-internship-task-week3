
# NextGenLearners Week 3 — SQL + Program Performance Dashboard

This project was completed as part of my Data Science Internship at NextGenLearners.

## Technologies Used

- Python
- SQL
- SQLite
- Pandas
- Streamlit

## Project Work

- Explored three related SQLite tables
- Wrote SQL queries using JOIN, LEFT JOIN, GROUP BY, COUNT and AVG
- Calculated completion rates
- Analyzed average hackathon scores
- Identified top performers
- Built an interactive Streamlit dashboard
- Added domain-based filtering

## Dashboard Features

- Total Applicants
- Completed Interns
- Completion Rate per Domain
- Average Hackathon Score per Domain
- Top 10 Performers Leaderboard
- Interactive Domain Filter
